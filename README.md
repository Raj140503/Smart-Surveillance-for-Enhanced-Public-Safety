
# Smart Surveillance System for Enhanced Public Safety

## 🛠 Tech Stack
- Programming Language: Python
- AI / ML: Deep Learning, Computer Vision
- Frameworks & Libraries: YOLO, OpenCV
- Concepts: Real-time video analytics, object detection, event classification

## ❓ What Problem It Solves
Traditional surveillance systems rely heavily on manual monitoring, which is inefficient and error-prone. This system automates the detection of critical safety events such as falls, intrusions, crowd congestion, and abandoned objects.

## 💡 Why I Built This
I wanted to explore how AI and computer vision can be used to solve real public safety challenges at scale. This project also helped me gain experience in designing end-to-end AI-powered systems and led to a patent filing.
